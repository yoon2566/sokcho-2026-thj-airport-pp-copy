## 수정과 실행

`source.template.html` 및 `src/`가 있으면 그 안의 게임 코드를 수정합니다. 자산은 `assets/`, 실행용 파일은 `index.html`입니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

빌드한 index.html을 Chrome 또는 Edge로 열어 실행합니다.
